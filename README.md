# DACUM 分析法 · 交互式学习网站

> Developing A CurriculUM（DACUM）是一套低成本、快速、有效的职业 / 岗位分析方法。本网站用交互式动画把它讲透——零基础也能看懂，并配套 6 个可直接复用的工具 + 10 个真实岗位案例。

🌐 **在线访问**：<https://lvzhongpei.github.io/dacum-guide/>

---

## 项目简介

DACUM（Developing A CurriculUM）由俄亥俄州立大学国家职业教育研究中心（NCRVE）发展成熟，核心做法是：召集 8–12 名一线专家工人组成委员会，在受训引导者带领下，用改良头脑风暴法界定某职业的「职责」（Duty）与「任务」（Task），产出一张「能力画像图」，作为胜任力本位课程开发的研究基础。

本网站以「动画讲解 + 自主操作 + 工具复用 + 真实案例」四种方式，帮助学习者一步步理解 DACUM 分析法的全貌。

## 配套工具（6 个）

1. **八步流程引导器** —— 逐步带你走完 DACUM 的 8 个步骤
2. **职责 / 任务卡片墙搭建器** —— 模拟工作坊贴墙过程，可添加 / 归类 duty 与 task
3. **任务陈述写作检查器** —— 自动检查是否符合「动词 + 宾语 + 限定语」及写作准则
4. **职责 vs 任务分类练习** —— 交互判断，帮助理解 duty 与 task 的区别
5. **验证问卷生成器** —— 按重要性 / 频率 / 入门 / 难度 / 关键性 5 类生成问卷
6. **DACUM 图表预览 / 导出器** —— 生成图表预览，支持导出 JSON / PNG

## 技术栈

- **纯静态** HTML / CSS / JS，零构建、零依赖
- **响应式多端兼容** —— 桌面 / 平板 / 手机（Pointer Events 统一处理鼠标与触摸）
- **苹果简约风 + 流体动态渐变背景** —— CSS `@keyframes` 实现轻量动态渐变
- **滚动触发 + 步骤点击** 混合动画，兼顾观赏与自主操作

## 首版产品目标

面向职业教育教师与培训负责人，帮助用户在约 15 分钟内完成一份岗位能力图初稿。网站采用本地优先设计：岗位资料保存于浏览器，用户主动导出 JSON 或打印稿；所有初稿均须由专家委员会验证。

首版主路径：岗位范围 → 职责与任务 → 自检 → 评分/验证准备 → 导出。真实案例会注明资料性质、来源和访问日期。
